# 烟雨江南 / 雪月江南 — 使用说明

一座以月洞门、斜梅、静水与听雨轩构成的可编辑庭院。题意取「致虚极，守静笃」：月光清冷，灯火温暖，空庭留白，风雨徐行。所有模型和材质均由脚本生成，不依赖游戏资产或外部贴图。

## 打开与播放

打开仓库根目录的 `Jiangnan.blend`，选择场景「烟雨江南 · 雪月江南」。时间轴为 1–240 帧、24 fps。播放时间轴可查看花枝摇摆、露珠随枝、雨雪下落、涟漪扩散、云层位移及水面变化。枝条使用原生驱动器，无需外部缓存；若 Blender 提示禁用驱动表达式，请为这个自己信任的文件启用脚本自动运行。

## 雨雪与风力

在集合 `JN_00_总控` 中选择 `JN_总控_天气0雨1雪_风力`，打开「物体属性 → 自定义属性」：

- `Weather = 0`：烟雨。细雨、涟漪、湿润石材。
- `Weather = 1`：雪夜。飘雪、瓦上薄雪、汀步薄雪、石上残雪；雨丝与雨涟漪自动隐藏。
- `Wind`：默认 0.7，建议 0–2，控制梅枝摇摆和飘雪横向幅度。

从 Python 修改自定义属性时，需要刷新依赖图：

```python
import bpy
ctrl = bpy.data.objects['JN_总控_天气0雨1雪_风力']
ctrl['Weather'] = 1
ctrl.update_tag()
bpy.context.scene.frame_set(bpy.context.scene.frame_current)
```

雨雪采用无缓存的循环位置驱动；雨滴和雪粒为可编辑实例。它们是用于庭院镜头的艺术化天气，不是碰撞模拟。屋檐遮挡由场景几何完成，未模拟水滴流淌或积雪增长。240 帧是预设播放长度，枝条和天气可继续播放，整段并非严格无缝循环。

## 重建

仓库根目录的 `jiangnan.py` 是权威副本（`.blend` 文本数据块中另嵌有一份生成时的快照）。脚本顶部 `PARAMS` 集中管理随机种子、天气、风力、花量、雨雪数量、分辨率、采样数及输出目录。改变参数后，在 Blender 文本编辑器运行即可重建同名场景。

输出目录约定：`output_dir` 下需有 `textures/` 子目录，脚本会在其中写出 `Jiangnan.blend`、`scene_statistics.json` 与 `renders/`。默认取当前 `.blend` 所在目录——仓库内 `Jiangnan.blend` 位于根目录，即开箱即用；也可用环境变量 `JN_OUT` 覆盖。

脚本只替换 `JN_` 前缀的生成资产和专用场景。请不要把希望永久保留的手工修改放入生成资产中；重建前另存一个文件。题字优先使用 Windows 楷体，已打包到交付 `.blend`；重新生成时若系统没有该字体，可把 `fontpath` 改成当地可用的中文字体。

`stage` 可设为 1–5，分别止于庭院、植被、雨雪、天空、灯光。默认 5。`render=True` 时，脚本完成后自动渲染正面、顶视、三分之四三个机位到 `renders/`。

## 集合与编辑

00 总控；01 庭院墙瓦月门；02 水石汀步；03 梅树可动花枝；04 露珠；05 夜雨；06 落雪；07 薄雪覆盖；08 云月远山；09 冷月暖灯；10 验证相机。

月洞门是真实贯通几何。枝干是可编辑曲线，花朵为五瓣网格，风动组可单独调整。石灯、茶案、瓦脊、题字及竹叶均为独立资产。雨雪复用几何数据以减少文件体积。远山采用分层轮廓，适合当前庭院机位；任意绕到远山背面时不应期待完整山体。

## 渲染与验证

使用 Cycles，默认 1600 × 1000、96 samples、降噪。正式渲染静帧在 `renders/`；`validation/scene_statistics.json` 记录基础网格数（不含曲线求值后的细分面数），`validation/validation.json` 记录天气互斥、驱动器有效性与帧间动态检查。完整验证与四机位出图可运行 `tools/verify_render.py`。

打开 `renders/gallery.html` 可在同机位切换烟雨与雪夜图片，并查看顶视、三分之四视图。网页展示的是渲染静帧；实际动态在 Blender 时间轴中播放。
