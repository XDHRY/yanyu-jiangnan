# 烟雨江南：空间诊断循环

> 2026-09-20 起停止“堆正式机位数量”的路线。正式多机位高采样渲染默认关闭，现阶段优先把空间、构造、尺度和动线做对。

## 固定循环

1. **重建**：由 `jiangnan.py` 从源码生成场景。
2. **断言**：`tools/verify_render.py` 只做结构/动画/贴图/空间连接验证；除非显式设置 `JN_FORMAL_RENDER=1`，不做正式多机位 Cycles 渲染。
3. **低成本观察**：`tools/diagnostic_review.py` 用 Eevee Next 输出 10 个 640×400 诊断机位。
4. **判断**：每个机位只回答一个空间问题，不追求成片感。
5. **修改**：优先改空间关系与构造，再改材质和氛围。
6. **再次诊断**：同一批机位用于前后对照；必要时替换机位，不固定死角度。
