## 实际建成内容

- 将北端西岸第四栋住宅转成用途明确的竹器作坊，没有增加一栋占位盒子。作坊与北街茶集相邻，原住宅真实门窗、山墙、室内地坪和屋面继续保留。
- 新增两处青石柱础、两根木檐柱、墙檩、前檐枋、5道承托椽与滴水檐口；披檐使用真实6cm Solidify厚度，后缘接墙檩，前缘由柱梁支撑，整体低于主屋檐。
- 新增陈列石座、四腿木案、两只开放竹篮、一个悬挂竹筛与无字木招牌。竹篮/挂筛用低半径曲线表达真实轮廓和编织方向；没有引入文字贴片或现代标识。
- 披檐外缘距西水街仍有0.99m退界，门前中央净空记录为1.2m。陈列案偏置在门轴一侧，不堵住宅到街道的既有入户路径。
- 依据第二轮原生近景，粉墙灰度Bump从强度0.28、距离0.035m降为0.10、0.012m；沿用原粉墙BaseColor，减少粗水泥浮雕感，不新增材质与位图。
- 候选资产清单见 `assets/architecture/bamboo-workshop/manifest.json`。LOD1/2、碰撞、导航和运行时尚未完成，不能按完成资产计入最终运行时库。

## 美术检查与未完成项

本轮效果是可编辑模型的真实低成本诊断图，不是概念图，也不是最终成片。作坊已从住宅复制体中形成明确用途和临街层次，粉墙从强烈颗粒回到较克制的石灰墙感。仍有以下债务：

- 披檐目前是清楚、可信的附属屋面，但瓦垄节奏和出檐曲线仍偏平；主屋八栋的屋面轮廓仍重复。
- 竹篮和挂筛在近景可读，曲线未折算为 evaluated runtime triangles，也没有LOD。
- 陈列案为结构正确的简洁木案，未达到最终明式精品家具等级；招牌故意无字，避免未验证的文字贴片。
- 街道大面积青石、岸线和生活植被仍单调，14号核心画面变化很小。
- 粉墙Bump已降低，但仍是灰度近似微凹凸，不是独立真实Normal/Roughness/AO套装。
- 碰撞、导航、UV/法线导出审计、运行时加载、Form与Runtime人类批准均未完成。

下一轮优先处理住宅屋面：建立至少两种共享的屋面/封火山墙变体，补檐下椽口和瓦当节奏，以实图拉开建筑主次；同时只在画面需要处增加岸边植物和生活器物。保持本轮竹器作坊、民居贯通洞口、北街茶集、完整父树和14个核心机位不回退。
