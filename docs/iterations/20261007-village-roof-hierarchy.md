## 实际建成内容

- 将八栋民居分为4栋标准脊和4栋高脊。高脊抬升18cm，并同步使用独立共享的高脊山墙和承檩；没有让屋面悬在旧山墙上。
- 八栋全部实例化一套檐椽列和一套八角瓦当列：每栋两侧各9根椽尾、9枚瓦当，椽顶按翘角高度贴合7cm实体屋面底面。轮廓和承托用几何，瓦面细损耗继续由既有材质承担。
- 北端东西两栋实例化同一套阶梯封火山墙墙身和黛瓦压顶，墙身下缘插入既有山墙，不悬空。两栋共享一套非对称收脊：临街端止于封火山墙内部，背街端保留正常挑出。
- 竹器作坊披檐、八栋贯通门窗、北街茶集、桥与双岸街道全部保留。本轮没有增加材质或位图，也没有从客栈库复制资产。
- 候选资产清单见 `assets/architecture/village-roof-hierarchy/manifest.json`。LOD、碰撞、导航、UV/导出审计与运行时仍未批准。

## 美术检查与未完成项

本轮效果是可编辑模型的真实低成本诊断图，不是概念图，也不是最终成片。民居不再是等高重复屋面，北端封火山墙建立了明确地标；椽口和瓦当让屋面从大灰面回到可读构造。仍有以下债务：

- 封火山墙采用低成本阶梯块体，轮廓和接缝已可信，但压顶转角、滴水与灰塑收头仍未达到最终精品等级。
- 主瓦面仍是共享低面数曲面配既有材质，没有逐垄高低和完整筒瓦/板瓦系统；不能误称为成品瓦作。
- 北端屋面层级在15/16号高位机位最清楚，12/14号人眼核心画面变化克制；下一批扩建仍需增加街道用途与生活密度。
- 街道青石、岸线植被和水边器物偏单调；竹篮曲线、屋脊曲线和修改器仍未折算 evaluated runtime triangles。
- 碰撞、导航、LOD、UV/法线导出审计、运行时加载、Form与Runtime人类批准均未完成。

下一轮优先在东岸建立与住宅相连的染布/纸作小院和河埠工作面，加入有支撑的晾架、染缸/纸槽、遮雨构架和少量岸边植物，以用途和垂直层次继续扩大水乡生活面；同时保留本轮两级屋面、封火山墙、竹器作坊、真实门窗、北街茶集与14个核心机位不回退。
