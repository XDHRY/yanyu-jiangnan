# 临水村落 Phase 1 落地清单

目标：把现有月门庭院向外扩成第一片可游览江南水巷，不修改既有庭院资产。

## 空间骨架
- 8 栋临水民居：水巷两岸各 4 栋。
- 24 段青石主巷：从月门向村落连续延伸。
- 约 25 m 水巷，双侧模块化石驳岸。
- 1 座木桥：11 段桥板、两侧栏柱。
- 1 处六级河埠。
- 两个诊断机位：村落总览、水巷人眼。

## 实时资产预算
- 单栋民居 LOD0 <= 1500 tris；LOD1 <= 700；LOD2 <= 180。
- Phase 1 新增总预算 <= 18000 tris。
- 墙体、屋面、门窗、桥板、栏柱必须共享 Mesh datablock。
- 复用 plaster / tile / wood / stone / darkstone / water 材质，不增加贴图显存。

## 验收
1. Blender 4.5 无头重建成功。
2. 原有断言继续通过。
3. 月门到村巷、木桥、河埠形成连续人眼动线。
4. 新增几何不超过 18k tris。
5. 两个新诊断机位无明显穿插、遮挡或尺度错误。
6. 记录新增对象数、tris、实例复用率和渲染时间。
